StarPort · 星港

        
本地应用聚合平台：统一入口、插件化接入、进程隔离、离线可用。

        
    
          
  • 内核：Python 标准库，无第三方依赖
    • 
          
  • 界面：原生窗口 + iframe 承载应用视图
    • 
          
  • 隔离：每个应用独立进程 + 独立端口，崩溃互不影响
    • 
          
  • 数据：全部落在 StarPort/data/，不联网
    • 
        

        

        
接入契约

        
一个应用 = 一个目录 + 一份 manifest.json。类型：

        
    
          
  • webservice：拉起本地服务进程，健康检查通过后嵌入
    • 
          
  • static：纯前端页面，由平台静态托管
    • 
          
  • external：原生程序，平台负责启动与回收
    • 
        

        
详见 README.md 与 apps/filecleanup/manifest.json。
